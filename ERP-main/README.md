# ERP System for VIVA School

A School Enterprise Resource Planning (ERP) System designed to help digitize and streamline school administration and academic management through a centralized web application.

## 📌 Project Overview

The **ERP System for VIVA School** is a web-based school management project that aims to simplify administrative and academic operations by organizing school-related information in one place.

The project follows a frontend and backend architecture. The frontend provides the user interface, while the backend handles application logic and data processing.

The goal is to reduce manual work, improve information management, and provide a more organized digital workflow for school operations.

## 🎯 Objectives

- Digitize school administration and academic workflows.
- Organize school-related information in a centralized system.
- Provide a user-friendly interface for interacting with the application.
- Separate frontend and backend responsibilities for maintainability.
- Build a foundation for expanding school management functionality.

## ⚙️ Installation and Setup

### Prerequisites

Install the tools required by your actual project, such as:

- Git
- The appropriate runtime for the frontend
- The appropriate runtime for the backend
- The database used by the application

### 1. Clone the repository

```bash
git clone https://github.com/Manasagundavarapu/ERP-system-for-VIVA-School.git
cd ERP-system-for-VIVA-School
```

### 2. Set up the backend

Navigate to the backend directory:

```bash
cd backend
```

Install backend dependencies using the package manager and instructions specified by the backend project.

Configure the required environment variables and database connection before starting the server.

### 3. Set up the frontend

Open a separate terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install the frontend dependencies using the package manager specified by the project.

Configure the backend API URL if required.

### 4. Run the application

Start the backend and frontend using the commands defined in their respective project configuration files.

Refer to the backend and frontend documentation for the exact commands, ports, and environment variables.

## 🔐 Configuration and Security

- Keep API keys, passwords, database credentials, and other secrets out of source control.
- Store sensitive configuration in environment variables.
- Do not commit real `.env` files containing credentials.
- Use example configuration files without real secrets when necessary.
